DESCRIPTION

r.in.snodas downloads daily NOAA Snow Data Assimilation System (SNODAS) rasters and imports them into GRASS GIS.

SNODAS provides spatially continuous estimates of snow water equivalent (SWE) and snow depth across the contiguous United States (CONUS) at approximately 1 km resolution, available from 2003-10-01 to near-present. Data are derived from a physically based land surface model that assimilates satellite, airborne, and ground observations (including SNOTEL stations). No authentication is required; data are fetched directly from NOAA over HTTPS.

Each day's data is imported as one or two FCELL raster maps, named <output>_swe_YYYYMMDD and/or <output>_depth_YYYYMMDD, automatically reprojected and clipped to the current GRASS computational region via r.import.

NOTES

Variables

variable=DescriptionUnits
swe Snow water equivalent mm
depth Snow depth mm

Both variables may be requested in a single run with variable=swe,depth.

Data source and coverage

SNODAS masked product (CONUS only):

  • Spatial coverage: contiguous United States
  • Native resolution: ~1 km (~30 arcseconds), geographic WGS84
  • Temporal coverage: 2003-10-01 to near-present
  • Update latency: ~1 day
  • Grid: 6935 columns × 3351 rows

Regions outside CONUS will produce empty rasters. For Alaska, Canada, or global snow cover, consider MODIS or ERA5 snow products.

Units

SNODAS raw values are stored in tenths of millimetres (scale factor 0.001 m). r.in.snodas converts to millimetres on import.

Relationship to SNOTEL

SNODAS is a gridded model product that assimilates SNOTEL station observations (among other sources) to produce spatially continuous snow fields. For actual observed station time series from the SNOTEL network, use v.in.snotel. SNODAS and SNOTEL are complementary: SNOTEL provides point ground truth; SNODAS provides spatial coverage.

Space-time raster datasets

Use the -t flag to register imported maps as GRASS space-time raster datasets (strds). A separate strds is created for each variable: <output>_swe and <output>_depth.

EXAMPLES

Import daily SWE for water year 2020 and register as strds: 
r.in.snodas output=snow variable=swe start=2019-10-01 end=2020-09-30 -t
Import both SWE and snow depth for a single date: 
r.in.snodas output=snow variable=swe,depth start=2020-04-01 end=2020-04-01
Compute snow cover area (fraction of region with SWE > 0): 
r.mapcalc "snow_cover_20200401 = if(snow_swe_20200401 > 0, 1, 0)"
r.univar snow_cover_20200401

REQUIREMENTS

  • Python packages: requests, numpy
  • GDAL CLI tools (gdal_translate) — typically installed with GRASS
